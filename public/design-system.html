02 — Type Scale

Typography

Font System
دیکته‌خونه از دو فونت اصلی استفاده می‌کند.

Shabnam برای Headingها، Titleها، Buttonها و عناصر مهم رابط کاربری.
Vazirmatn برای متن‌های اصلی، توضیحات، مقالات و محتوای آموزشی.

برای بهینه‌سازی Performance فقط وزن‌های مورد استفاده در پروژه لود می‌شوند. 


  --font-shabnam-medium: "Shabnam-medium", sans-serif;
  --font-shabnam-bold: "Shabnam-bold", sans-serif;

  --font-vazirmatn-regular: "Vazirmatn-regular", sans-serif;
  --font-vazirmatn-medium: "Vazirmatn-medium", sans-serif;
  --font-vazirmatn-bold: "Vazirmatn-bold", sans-serif;
Type Scale — از h1 تا span

عنوان اصلی صفحه

SECTION LABEL

این متن برای توضیحات مهم، معرفی بخش‌ها و لید پاراگراف‌ها استفاده می‌شود.

lead text-lg font-vazirmatn-medium text-textColor leading-relaxed
font-size: 18px · Vazirmatn Medium (500) · line-height: 1.8

این یه پاراگراف معمولیه. متن اصلی بدنه صفحه که باید خوانایی بالایی داشته باشه و لاین‌هایتش کافی باشه.

p text-body font-vazirmatn-regular text-textColor leading-relaxed

متن فرعی، توضیحات کوچک، تاریخ و اطلاعات ثانویه.

small / muted text-sm font-vazirmatn-regular text-mutedColor leading-relaxed

این یه جمله‌ست که توش هایلایت رنگی داریم و همچنین رنگ ثانویه و گرادیانت برند.

span text-primary font-vazirmatn-bold text-secondary font-vazirmatn-bold bg-gradient-to-r from-primary to-secondary bg-clip-text text-transparent

⚠️ نکته: چون --radius-sm/md/lg/xl رو تو @theme تعریف کردی، مقادیر پیش‌فرض تیلویند (مثل rounded-md: 6px) رو override میکنن. یعنی rounded-sm حالا 16px میشه، نه 4px پیش‌فرض تیلویند. این intentional هستش.
کِجا چی بزن:
· rounded-xl — hero section، splash card، صفحه‌ی اصلی دیکته
· rounded-lg — کارت درس، کارت نتیجه، پنل سایدبار
· rounded-md — کارت آمار کوچیک، input field، dropdown
· rounded-sm — badge، chip، tag، avatar
· rounded-full — دکمه pill، toggle، avatar دایره

            dark:border-border-dark-soft
            dark:shadow-glass-dark">

<div class="dark:bg-surface-dark
            dark:border-border-dark
            dark:shadow-card-dark">

<!-- Floating / Strong -->
<div class="dark:bg-surface-dark-strong
            dark:border-border-dark-strong
            dark:shadow-floating-dark">
Dark Mode Rules
Soft: Header، کارت‌های کم‌ارتفاع و سطوح سبک.
Default: کارت‌های اصلی محتوا و Video Card.
Strong: Dropdown، Modal، Drawer و Floating UI.

در Dark Mode از shadowهای Light برای ایجاد Depth استفاده نمی‌شود. هر سطح باید Border و Shadow متناظر خودش را داشته باشد.

11 — Usage

نحوه استفاده از توکن‌ها در Tailwind v4

روش صحیح — Arbitrary Value با CSS var
در تیلویند v4 توکن‌های @theme مستقیم به CSS custom property تبدیل میشن. برای استفاده از اونا در کلاس‌های arbitrary باید از var() یا shorthand استفاده کنی: 
<!-- رنگ پس‌زمینه -->
<div class="bg-bg">...</div>

<!-- رنگ متن -->
<p class="text-textColorColor">...</p>
<p class="text-mutedColor">...</p>

<!-- border radius -->
<div class="rounded-md">...</div>

<!-- shadow -->
<div class="shadow-card">...</div>

<!-- backdrop blur -->
<div class="backdrop-blur-md">...</div>

<!-- font -->
<p class="font-sans">...</p>
یه کارت کامل از صفر 
<div class="bg-surface backdrop-blur-md
            border border-white/65
            rounded-lg
            shadow-card
            p-6 space-y-3">

  <h3 class="text-2xl font-bold text-textColorColor">
    عنوان کارت
  </h3>

  <p class="text-sm text-mutedColor leading-relaxed">
    توضیحات کارت اینجاست
  </p>

  <button class="bg-primary text-white
                 rounded-full px-6 py-2.5
                 text-sm font-bold
                 shadow-btn
                 hover:opacity-90 transition-opacity">
    بیشتر بخوان
  </button>

</div>
